Beginner — Core REST fundamentals
Todo List API — Basic CRUD (Create, Read, Update, Delete) on a single resource. Path/query params, request bodies, status codes.
Notes API — Same CRUD pattern but add search/filtering by query params, and pagination (limit, offset).
URL Shortener — Generate short codes, redirect on GET, track click counts. Teaches path operations, redirects, and simple in-memory or DB storage.
Quotes/Jokes Random API — GET endpoint returning random items from a dataset. Good for practicing response models and static data serving.
Simple Calculator API — POST endpoints for math operations. Focus on request validation with Pydantic (types, constraints, custom validators).
Intermediate — Real-world patterns
User Auth API — Signup/login with JWT tokens, password hashing (passlib/bcrypt), OAuth2PasswordBearer flow. Core FastAPI security.
Blog/CMS API — Users, Posts, Comments with relationships (foreign keys). Introduces SQLAlchemy/SQLModel with a real relational schema.
File Upload/Download API — Handle UploadFile, save to disk or cloud storage (S3), serve files back, validate file types/sizes.
E-commerce Cart API — Products, Cart, Orders. Teaches nested Pydantic models, business logic (stock checks, totals), and transactions.
Weather/Proxy API — Wrap an external API (like OpenWeather) with caching. Teaches httpx async calls, error handling for upstream failures.
Task Queue API — Submit background jobs using FastAPI's BackgroundTasks, or Celery/Redis for real async job processing.
Chat/Messaging API with WebSockets — Real-time bidirectional communication, connection management, broadcasting.
Advanced — Production-grade concerns
Multi-tenant SaaS API — Role-based access control (RBAC), tenant isolation, dependency injection for permissions (Depends).
Rate-Limited Public API — Add rate limiting (slowapi/Redis), API key management, usage quotas per client.
Microservices with Inter-service Communication — Split into 2-3 services (e.g., Auth service + Orders service) communicating via REST or message broker (RabbitMQ/Kafka).
GraphQL Hybrid API — Add a GraphQL endpoint alongside REST using Strawberry or Ariadne, compare trade-offs.
Event-Driven API — Use webhooks (both sending and receiving), event sourcing basics, idempotency keys.
Full Observability Stack — Add structured logging, Prometheus metrics, OpenTelemetry tracing, health/readiness probes.
CI/CD + Dockerized API — Dockerfile, docker-compose (API + Postgres + Redis), GitHub Actions for tests/lint/deploy.
High-Performance Streaming API — Server-Sent Events (SSE) or streaming responses for large payloads (e.g., LLM-style token streaming, video/audio chunking).
Bonus — Specialized/niche
GraphQL-to-REST Gateway
Payment Integration API (Stripe test mode — webhooks, idempotency)
Recommendation Engine API (simple ML model served via FastAPI + scikit-learn)
Multi-language i18n API (content negotiation via Accept-Language header)
Testing-focused API — same Todo API but built test-first with pytest + TestClient, covering unit/integration tests and mocking DB calls
